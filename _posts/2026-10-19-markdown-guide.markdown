## 正文

Markdown 是一种轻量级的标记语言。简单说，就是用一些特殊的符号来给纯文本排版，让普通文字变成带标题、列表、加粗、代码块的漂亮文档。它最大的好处是：**写起来简单，记起来容易，而且 GitHub、博客、各种笔记软件都支持**。

下面是我整理的最常用语法。


### 1. 标题

在文字前面加 `#` 就是标题。`#` 越多，标题越小。

```
# 这是一级标题
## 这是二级标题
### 这是三级标题
#### 这是四级标题
```

注意 `#` 后面要跟一个空格。一篇文章建议只用一个大标题（一级标题），下面的小节用二级、三级。


### 2. 加粗和斜体

用两个 `*` 包起来是加粗，用一个 `*` 包起来是斜体。

```
**这是加粗**
*这是斜体*
```

效果：**这是加粗**，*这是斜体*。


### 3. 列表

无序列表用 `-` 或 `*` 开头，有序列表用 `1.` 开头。

```
- 项目一
- 项目二

1. 第一步
2. 第二步
```

效果：

- 项目一
- 项目二

1. 第一步
2. 第二步


### 4. 链接和图片

链接的语法是 `[显示的文字](网址)`：

```
[我的 GitHub](https://github.com/CCLLYK)
```

效果：[我的 GitHub](https://github.com/CCLLYK)

图片的语法是在链接前面加一个 `!`：

```
![图片描述](图片路径)
```

图片可以放在 `img/in-post/` 目录下，描述文字在图片加载失败时会显示出来。


### 5. 代码

代码有两种写法。行内代码用单个反引号包起来：

```
执行 `git push` 就能发布文章
```

大段代码用三个反引号包起来，可以在后面写语言名，代码会自动高亮：

````markdown
```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```
````

常见的语言标识有 `c`、`cpp`、`python`、`bash`、`java` 等。


### 6. 引用块

在行首加 `>` 就是引用，适合放名言、他人观点。

```
> 学而不思则罔，思而不学则殆。
```

效果：

> 学而不思则罔，思而不学则殆。


### 7. 分割线

三个短横线 `---` 就是一条分割线，用来分隔上下内容。


### 8. 目录 / 锚点跳转

长文章可以加一个"目录"，让读者点击跳转到指定小节。方法是先在小标题处放一个锚点（HTML 标签）：

```html
<p id="正文"></p>
```

然后在文章开头放跳转链接：

```
[点击跳转到正文](#正文)
```
