### 2. 常用语法示例

#### 2.1 加粗与斜体

**这段文字是加粗的** —— 用两个星号包起来。

*这段文字是斜体的* —— 用一个星号包起来。

#### 2.2 列表

**无序列表**（用 `-` 或 `*` 开头）：

- 项目一
- 项目二
- 项目三

**有序列表**（用 `1.` 开头，数字会自动编号）：

1. 第一步
2. 第二步
3. 第三步

#### 2.3 链接

这是一个[链接文字](https://example.com)，点击跳转到外部网站。

**语法解释**：`[链接显示的文字](网址)` 中间不要有空格。

#### 2.4 图片

<!-- 嵌入图片的语法：![图片描述](图片路径) -->
![图片描述文字](img/in-post/你的图片.jpg)

**语法解释**：
- 图片放在 `img/in-post/` 目录下（没有可以自己建）
- `!` 开头表示这是图片，方括号里写图片描述（图片加载失败时显示的文字），圆括号里写图片路径

#### 2.5 代码

**行内代码**：比如 `git commit -m "message"`，用反引号（键盘上数字 1 左边那个键）包起来。

**代码块**：用三个反引号包裹，可以在开头指定语言，代码会自动高亮：

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```

其他常用语言标识：

```python
print("Hello World")
```

```cpp
#include <iostream>
int main() {
    std::cout << "Hello World" << std::endl;
    return 0;
}
```

```bash
ls -la
```

**语法解释**：开头的三个反引号后面写语言名（如 `c`、`cpp`、`python`、`bash`、`java`、`javascript`），GitHub Pages 会自动高亮。

#### 2.6 引用块

> 这是一段引用文字，适合放别人的话、官方文档原文等。
> 每一行开头用 `>` 即可。

#### 2.7 目录 / 锚点跳转

如果你想在文章里做一个"目录"，让读者点击跳转到对应小节：

**第一步**：在正文的小标题上添加自定义锚点，格式如下（HTML 语法）：

```html
<p id="正文"></p>
```

**第二步**：在文章开头放跳转链接：

```
[点击跳转到正文](#正文)
```

点击后页面会自动滚动到锚点所在位置。
